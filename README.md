## Описание программы 
*"Expense Tracker (Трекер расходов) — это консольное приложение позволяющее добавлять, просматривать и фильтровать записи о погоде, сохранять данные в JSON и использовать Git."*

## Требования для запуска 
Что нужно установить на компьютер:
- Python 3.10 или выше
- Библиотеки: `pip install matplotlib requests`
